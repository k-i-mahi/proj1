# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, use
[GitHub's private vulnerability reporting](https://github.com/k-i-mahi/proj1/security/advisories/new)
with steps to reproduce and the impact you observed. You can expect a reply within a
few days.

## Supported versions

| Version | Supported                      |
| ------- | ------------------------------ |
| 2.x     | Yes                            |
| 1.x     | No (legacy university project) |

The security design (token handling, validation, upload checks, rate limits) is
described in the [README](README.md#security).
